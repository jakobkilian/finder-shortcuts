## get-path

get-path returns the path of the selected file or directory (if non is selected: the current directory) to your clipboard. 

There is a dialogue window to chose between returning the plain path (e.g. `/Users/username/example.md`) and the URI style link (e.g. `file:///Users/username/example.md`). The URI link can e.g. be used in markdown files or obsidian notes to link to that file/dir.
